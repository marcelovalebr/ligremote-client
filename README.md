# LIG Remote

Cliente de acesso remoto da LIG-it Tecnologia.

**Este programa é uma versão modificada do [RustDesk](https://github.com/rustdesk/rustdesk)**
(versão 1.5.1), software livre licenciado sob a GNU AGPL-3.0 (arquivo `LICENCE`).
"RustDesk" é marca dos seus respectivos titulares; este produto não é afiliado à RustDesk.

Modificações em relação ao upstream (todas aplicadas por `rebrand.py`, ADR 0046 da LIG-it):
nome e ícones do aplicativo, metadados do executável, links para o site do produto,
servidor padrão sem configuração, gravação do relay na instalação e workflow de build Windows.

Código-fonte completo desta versão: https://github.com/marcelovalebr/ligremote-client

O README original do RustDesk está em `README-RustDesk.md`.
